let - a keyword for variable declaration which the value can be updated later
const - a keyword for variable declaration but the value cannot be updated
number - a primitive data type for numeric type
string - a primitive data type for strings or text type. It should be inside a "" for it to be considered as string
Boolean - a primitive data type that have only 2 values either true or false
=== - this is for strict equality shows true if both are equal and same type
if/else - a JS statement to check if the condition is true otherwise it will perform another code
for...of - a JS statement that will loop over the values of any iterable
switch - a JS statement that will execute a code depending on the different conditions
bigint - a primitive data type for big integers
